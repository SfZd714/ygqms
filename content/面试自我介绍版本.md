## 2分钟版：技术面

> 我的经历可以分为三个阶段。第一阶段是嵌入式软件开发，我做过 UART 通信协议和上位机交互模块，参与协议格式、数据结构、分片传输和 CRC16 校验，也接触过 STM32 控制开发。这段经历让我熟悉了底层接口、调试和模块联调。
>
> 第二阶段是工业知识库项目。我在三人协作的知识库子系统中负责知识注册、混合检索问答和知识图谱根因分析。项目中我发现固定长度分块会破坏故障因果链，因此采用标题层级感知和两阶段分块；发现单路向量检索对设备编号不稳定，因此采用向量、关键词和精确匹配三路召回，再使用 RRF 和重排序；发现反向图谱遍历沿用永久 visited 会漏掉菱形结构中的独立路径，因此采用路径级 visited 回溯。整个过程让我从实现功能进一步转向用测试验证系统是否正确。
>
> 第三阶段是 Java 后端实践。我用 Spring Boot、LangChain4j、Redis、PostgreSQL/ParadeDB 和 Docker 完成过 AI Agent 后端，实践了 REST/SSE、会话记忆、RAG、工具调用、异常处理和监控。我的发展方向是软件开发和信息化工程，AI 是可以迁移和加强的技术能力，而不是对岗位的限制。
